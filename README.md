# 合唱团多机位录音对齐混音台

浏览器内的多轨录音对齐 / 混音 / 导出工具，纯 TypeScript + Web Audio，无后端、无运行时第三方依赖。
解决合唱团排练时多部手机各自录音、起点不一致、采样时钟有漂移导致「越往后越对不齐」的问题。

## 功能与页面对应

| 页面 | 能力 |
| --- | --- |
| **排练** | 新建 / 改名 / 删除排练；工程打包导出（`.camx`）与导入 |
| **素材** | 拖拽或选择音频，浏览器解码并生成波形包络；坏文件标红提示、不允许建轨 |
| **对齐** | 一键互相关自动对齐（含时钟漂移估计与重采样补偿）；手动拖拽微调，10ms 吸附（Shift 1ms，Ctrl 自由）；参考轨切换；头/尾延迟、ppm、残差、置信度诊断 |
| **混音** | 每轨音量 / 声像 / 静音 / 独奏，实时电平表；双击波形剪掉开头闲聊或中间停顿（再双击恢复），剪辑不改变对齐 |
| **导出** | 立体声混音 WAV（16/24/32-bit）；按轨导出对齐后的分轨 WAV（统一时间轴、补零对齐）；工程打包 |

工程数据（元数据）与原始音频字节分开存于浏览器 IndexedDB，所有改动防抖自动落盘。
`.camx` 本质是一个 STORE 模式 ZIP：`project.json` + `audio/*` 原始文件，可发给别人导入继续编辑。

## 快速开始

```bash
npm install
npm run dev        # 启动开发服务器
npm run build      # 类型检查 + 生产构建到 dist/
npm run gen:test   # 生成带已知偏移/漂移的测试音频到 test-output/
```

## 对齐算法（`src/dsp/`）

1. **互相关找延迟** `xcorr.ts`：FFT 计算循环互相关，峰值三点抛物插值得到亚采样精度。
   默认用能量归一化的普通互相关——对带瞬态的音乐比 GCC-PHAT 更稳（PHAT 在节拍周期处会产生等高假峰，仍保留为可选项）。
2. **时钟漂移估计** `alignment.ts`：沿时间轴取 6 个窗口分别估延迟，对「延迟 ~ 时间」做直线拟合，
   斜率即漂移（ppm）、截距即补偿后的恒定偏移。为抵御周期假峰，采用
   **锚点局部重搜（按各窗相关峰总分选全局锚点）+ RANSAC 鲁棒拟合（8ms 容差剔除错峰窗）**。
3. **重采样补偿** `resample.ts`：16 阶 Blackman 加窗 sinc 插值，按 `1 + ppm/1e6` 变速；
   播放与离线导出通过 `AudioBufferSourceNode.playbackRate` 实时应用，无需预先重采样整条音频。
4. **内存友好**：对齐只抽取 6×12s 的短窗口（`alignment-service.ts`），不缓存整条单声道信号，
   30 分钟多轨录音的对齐额外内存为 MB 级。

时间模型：素材自身时间 `u` 与工程时间 `t` 的关系为
`t = (offsetSec + nudgeSec) + u·(1 + driftPpm/1e6)`。
剪辑（`arrangement.ts`）只在素材时间轴上求「剪掉区间」的补集，绝不改动 offset/rate，因此对齐关系不受影响。

## 测试与验收

```bash
npm test          # Node 纯 DSP 测试（含严格 30 分钟长录音），约 5 分钟
npm run test:fast # 跳过 30 分钟长测的快速版，约 1 分钟
npm run test:e2e  # Playwright 浏览器端到端（需先 npm run dev）
```

- **DSP 单元/集成测试（69 项）**：FFT 对照朴素 DFT、互相关整数/亚采样偏移、sinc 重采样往返、
  WAV 16/24/32-bit 与立体声往返、ZIP/CRC32、剪辑几何，以及**带已知偏移和漂移的端到端对齐**。
  其中快速集 53 项（约 1 分钟），30 分钟长测 16 项。
- **30 分钟验收**：8kHz 下 4 组场景（含 ±漂移、晚录 2s、尾截），补偿后**头部和尾部残差全部 < 1ms**，
  ppm 误差 < 2，恒定偏移误差 < 1ms。
- **浏览器 E2E（25 项）**：真实驱动 UI 完成 建排练→上传→建轨→自动对齐→对照真值→混音→
  导出 WAV 并解码校验→工程打包往返→坏文件标红 全流程。浏览器内对齐真值误差：偏移 < 1ms、ppm 误差 < 5。

测试音频由 `scripts/generate-test-audio.ts` 用可种子化 PRNG 生成（和声 + 非周期随机拍点 + 噪声），
每条「手机录音」按物理模型施加已知起始偏移和 ppm 级时钟漂移，真值随文件名给出，可手工对照。

## 目录结构

```
src/
  dsp/            纯 DSP：FFT、互相关、漂移估计、sinc 重采样、WAV、波形包络、时间轴几何
  audio/          Web Audio 播放/离线渲染引擎、对齐服务
  storage/        IndexedDB 封装
  model/          数据模型与中央状态（自动持久化、.camx 打包）
  ui/             五个页面、时间轴/走带组件、样式
  util/           ZIP、格式化等纯工具
public/           AudioWorklet（电平表），原样部署
tests/            Node DSP 测试 + Playwright E2E
scripts/          测试音频生成
```
